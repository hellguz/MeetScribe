# MeetScribe

## Changelog

Every major, user-facing feature must get an entry in the in-app changelog: the
`CHANGELOG` array in `frontend/src/components/InfoPanel.tsx`, newest month first.
Add it in the same PR as the feature.

- A **highlight** (max two per month) is something that changes what you can do
  with the app. Everything else is a one-line entry in `lines`.
- Write for a long-time user with two minutes: plain language, short, no
  implementation detail.
- If the month already has an entry, add to it instead of creating a new one.
